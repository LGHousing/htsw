# Icon provenance

These 64x64 PNGs are rasterized versions of the [Lucide icon set](https://github.com/lucide-icons/lucide).
They were added to HTSW on 2026-05-07; the exact upstream revision was not
recorded. Lucide is ISC-licensed, with some icons derived from Feather under
MIT. Both notices are retained in the repository's `THIRD_PARTY_NOTICES.txt`
and included in HTSW release artifacts.
